FACULDADE GRAN (https://faculdade.grancursosonline.com.br/)

Projeto Disciplina Projeto Integrador

## Estrutura

- `backend/` — API REST em Node.js (Express + SQLite embutido) com os controllers de Produto, Fornecedor e Associação Produto/Fornecedor.
- `frontend/` — Aplicação React (Vite) com as páginas de Produtos, Fornecedores e Associação Produto/Fornecedor.

## Como rodar

### Backend

```
cd backend
npm install
npm start
```

Servidor disponível em `http://localhost:3000`.

### Frontend

```
cd frontend
npm install
npm run dev
```

Aplicação disponível em `http://localhost:5173`.
